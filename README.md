# MVP-тренажёры для встраивания в Google Sites

Четыре самодостаточных HTML-файла. Каждый открывается сам по себе и не требует сервера.

| Папка | Что это | Высота iframe | Внешние зависимости |
|---|---|---|---|
| `doodle-math/` | Прыгай и считай (монстр, таблица умножения) | 720 px | нет |
| `music-studio/` | Музыкальная студия (ноты, ударные, 3 дорожки) | 820 px | нет |
| `hanzi-hsk1/` | Учим иероглифы (60 знаков HSK 1, 6 тем) | 800 px | Hanzi Writer и данные черт с cdn.jsdelivr.net |
| `archimedes-lab/` | Тонет или плавает (плотность, закон Архимеда) | 900 px | нет |

## Как встроить в Google Sites

1. Откройте сайт на sites.google.com в режиме редактирования.
2. Справа вкладка **Вставить** → **Встроить** → вкладка **Код для встраивания**.
3. Откройте нужный `index.html` в текстовом редакторе, скопируйте **весь** файл и вставьте в поле. Нажмите **Далее** → **Вставить**.
4. Растяните блок по высоте из таблицы выше (иначе появится внутренняя прокрутка).
5. Нажмите **Опубликовать**. Проверьте на телефоне по публичной ссылке.

Если Google Sites отказывается принять код (слишком большой размер), выложите файл на GitHub Pages и используйте вкладку **По URL**.

## Что проверить после вставки

- **Звук** включается только после первого касания или клика (правило браузеров). Это нормально.
- **Сохранение.** В iframe `localStorage` может не работать. Тренажёры при этом не ломаются, но рекорд и «выученные» иероглифы могут не сохраниться. Студия сохраняет проект через кнопки «Сохранить в файл» и «Открыть файл».
- **Иероглифы** требуют доступа к cdn.jsdelivr.net. Если у ученика он закрыт, иероглифы не появятся.

## Лицензии и источники

- Иероглифы: [Hanzi Writer](https://hanziwriter.org) (MIT), данные черт [Make Me a Hanzi](https://github.com/skishore/makemeahanzi). Ссылки на авторов оставлены в подвале страницы, не удаляйте их.
- Остальное написано с нуля, внешних картинок и звуковых файлов нет.
